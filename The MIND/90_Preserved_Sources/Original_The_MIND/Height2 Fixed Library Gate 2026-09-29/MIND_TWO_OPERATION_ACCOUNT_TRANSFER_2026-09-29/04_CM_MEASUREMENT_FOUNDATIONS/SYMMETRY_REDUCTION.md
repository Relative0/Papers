# Symmetry Reduction and Logical Differentiation

## 1. Two symmetry notions must be separated

The 2015 thesis calls a binary CM symmetric when `A=A^T`. For a truth-table matrix this is exactly the condition

`Theta(x,y)=Theta(y,x)`,

so it is simply **commutativity under operand exchange**. Exhaustive enumeration gives 8 transpose-symmetric and 8 transpose-asymmetric binary connectives.

A broader natural frame-symmetry group is the order-eight group generated by:

- swapping `X` and `Y`;
- negating `X`;
- negating `Y`.

On the square of four valuations this is `D_4`. The audit therefore also computed each truth support's `D_4` stabilizer and orbit.

## 2. Restriction does not monotonically break symmetry

For a support state `S` and a true-outcome effect `E`, the canonical update is

`M_E(S)=S intersect E`.

Among all 16x16 binary state/effect pairs, restricting to nonempty proper updates produced:

- **30** stabilizer decreases;
- **8** stabilizer increases;
- **72** stabilizer-preserving updates.

Hence the proposed criterion

`|Stab(M_E(S))| < |Stab(S)|`

cannot define or characterize measurement-induced distinguishability.

### Counterexample: restriction can increase symmetry

`S = X_IMPLIES_Y` has three valuations and `|Stab_D4(S)|=2`.

Restrict by `E=XNOR`. The result is `XNOR`, which has two valuations but stabilizer size 4. The state has become more selective while also becoming more symmetric.

### Example: restriction can decrease symmetry

`S=XOR` has stabilizer size 4. Restrict by `X_AND_NOT_Y`; the singleton result has stabilizer size 2.

### Example: support can shrink with no stabilizer change

`S=X` restricted by AND becomes AND, reducing support size 2 to 1 while the `D_4` stabilizer remains 2.

## 3. Structural reason

If `M` is equivariant under a group `G`, then every symmetry of `x` remains a symmetry of `M(x)`:

`Stab_G(x) subseteq Stab_G(M(x))`.

Therefore a stabilizer decrease requires the observation context/effect itself to break part of the original symmetry, or requires changing the acting group. A fixed effect `E` is generally equivariant only under its own stabilizer subgroup.

This shows that "measurement breaks symmetry" is not an intrinsic theorem of measurement. It is a statement about the combined system **state + chosen effect/context**.

## 4. Better notions of differentiation

### Observational differentiation

Given an observation family `Phi`, use the signature partition

`v ~_Phi w <=> o_Phi(v)=o_Phi(w)`.

Adding `psi` strictly increases distinguishability iff it splits an existing signature block.

### Selective information gain

Given support `S`, a possible true outcome gives

`S' = S intersect E`.

Under a uniform prior the Hartley information gain is

`log2(|S|/|S'|)`.

This measures uncertainty reduction, not symmetry.

### Symmetry reduction

If symmetry itself matters, record stabilizers separately. A useful triplet is therefore

`(number of observation blocks, support uncertainty, symmetry stabilizer)`.

No single one of these should be treated as a proxy for the other two.

## 5. Complete differentiation example

The path

`TRUE -> XOR -> X_AND_NOT_Y`

uses only valid restrictions. Support size decreases `4 -> 2 -> 1`. Under operand swap, TRUE and XOR remain symmetric, whereas the final singleton is asymmetric. Thus differentiation begins before thesis-style symmetry breaking occurs.
