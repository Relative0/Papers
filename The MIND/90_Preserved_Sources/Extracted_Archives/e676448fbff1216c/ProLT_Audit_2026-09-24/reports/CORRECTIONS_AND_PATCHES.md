# Corrections and patches

**Audit:** 24 September 2026. These are proposed replacements, not silently edited versions of the supplied manuscripts. Original files remain unchanged in the source snapshot. Claim IDs refer to `CLAIM_AUDIT_TABLE.csv`; proofs A1-A6 are in `AUDIT_ADDITIONS_AND_PROOFS.md`.

## Submission-blocking mathematical corrections

### C01. Delete the equality with classical 2-dimension

**Original:** v0.5, Proposition `prop:2dim`, TeX line 248: for a total coarse order P, odim_P(Q)=dim_2(Q).

**Verdict:** FALSE. This is structural, not a missing technical hypothesis.

Let P=Q be the two-element chain. No observation is needed, so odim_P(Q)=0, whereas classical Boolean-lattice embedding dimension is 1. Even forbidding the zero-coordinate example does not rescue the statement: if P is the two-chain x<y and Q the two-point antichain, one bit b(x)=1,b(y)=0 works, but the antichain needs Boolean-lattice dimension 2.

The failed proof forgets that P already blocks reverse ordered pairs. An observation label need not be injective or reflect every ordered pair, whereas an ordinary Boolean-lattice embedding must do both. The defect is not repaired by requiring positive k or nonredundancy.

**Replacement:** retain dim_2(Q) only as an upper bound. Put D={<_P comparisons absent from Q}. On D make demands (x,y),(u,v) adjacent exactly when x<=_Q v or u<=_Q y. Then

    odim_P(Q) = chromatic number of this conflict graph.

Equivalently, it is generalized Boolean rank of the matrix with zeros on Q, ones on P minus Q, and question marks elsewhere. Full proof: A2. Credit the generalized covering framework in R07-R08. Whether this precise restricted poset family has previously received a dedicated name remains unclear; do not market it as a wholly new dimension theory.

### C02. Withdraw the inherited total-order NP-completeness proof

**Original:** v0.5, “Complexity inheritance,” line 263, downstream of C01.

**Verdict:** NEEDS MAJOR REPAIR. The proof fails; this audit does not prove the asserted total-coarse-order restriction either true or false.

**Replacement proved in this audit:** given explicit finite relations Q subset P on the same vertex set and k, deciding odim_P(Q)<=k is NP-complete. Hardness holds already for k=3 and height(P)<=1. For a graph H, take minima a_i and maxima b_i; Q contains a_i<b_j for edges ij, and P additionally contains a_i<b_i. The demands' conflict graph is H. A certificate uses at most n coordinates, giving NP membership. This reduction is polynomial in the explicit relation input.

**Downstream impact:** the original proposed Paper C loses its foundational identification and its advertised restricted-hardness proof. No chain-topology, repair-forest, block-matrix, or interaction theorem depends on this equality; those branches survive. Replace ledger summaries and abstracts that say NP-completeness “inherits” from ordinary 2-dimension.

### C03. Repair the rooted-forest translation's missing rows

**Original:** v0.5, setup before Theorem `thm:rootedtranslation`, line 339: G is generated by the deleted triangles, and its nonroot edges are identified with all deleted edges.

**Problem:** a deleted edge need not lie in a triangle. For a two-chain with bit word 10, there is one deleted edge and no triangles. The original G is empty, but the actual relative matrix has one row and no columns. Thus the asserted general matrix identification is false as written.

**Minimal corrected setup:** take G to contain the **entire coarse one-skeleton**, together with precisely the deleted triangles, and let R contain all vertices and retained edges. Then the reduced boundary rows are exactly all deleted edges. Alternatively, explicitly detect unsupported deleted edges first and reject neutrality before using the triangle-generated G.

If the relative matrix is square and nonsingular, an unsupported deleted edge is impossible, so the main nonsingular/rooted-forest equivalence and the named neutral examples survive. This is a local setup repair, not a failure of the Bernardi-Klivans determinant theorem. For rectangular matrices, state the full kernel/cokernel rather than a determinant.

### C05. Qualify nonempty universality

v0.2 Theorem `thm:universality` and Corollary `cor:alltypes` should say nonempty finite poset/complex when the coarse quotient is a point on a nonempty carrier. A surjective signature map from a nonempty carrier cannot have empty image. Empty carriers may be handled separately; specify the convention for the void complex and reduced degree -1 homology. The undecidability reduction uses nonempty complexes and is unaffected.

### C06. State the current state carrier consistently

Use S subset Omega_P for an allowed current model set. A post-T0 carrier with n states need not be the entire 2^m-valuation space. Every finite example can be realized on a definable restricted carrier by minterms. For unrestricted full-carrier formulations, explicitly construct a suitable fiber realization or padded instance instead of assuming an arbitrary n is a power of two. This is particularly important for three-, five-, and thirteen-state examples. The finite-poset theorems themselves are unaffected.

### C07. Keep three different homotopy notions separate

The finite Kolmogorov quotient is an ordinary homotopy equivalence. McCord's realization map is a weak homotopy equivalence. The Quillen/Barmak results in v0.2 concern homotopy or simple-homotopy equivalence of **order complexes**; the source correctly states the simple version already. Beat-point contractibility of a finite poset is stronger than contractibility of its order complex. Do not replace order-complex contractibility with a beat-reduction test as an unrestricted equivalence.

The undecidability claim is about Delta(r), not ordinary homotopy equivalence of finite spaces. Finite-map homotopy is a finite combinatorial problem, so conflating those decision problems would materially misstate the result.

### C08. Fix the syzygy phrase in v0.1 Example B

For I=(x1*x2*x3), the quotient S/I has the standard minimal resolution

    0 -> S(-3) -> S -> S/I -> 0.

Hochster's formula records beta_(1,{1,2,3})(S/I)=1. This is the minimal generator of I as seen in the quotient resolution; the principal ideal itself has no nontrivial first module syzygy. Replace “unique first syzygetic/topological event” with this precise statement. The triangle-boundary homology and inconsistency-ideal calculations are correct.

### C09. Preserve Horn and semilattice hypotheses

v0.4's Horn/dual-Horn corollaries are valid **as qualified**. Keep the ambient realized meet/join-semilattice, restriction of the model/falsity set, and upper/lower cofinality assumptions. “Horn observations preserve homotopy” is not an acceptable abbreviated theorem. NOR on the full Boolean square already illustrates how a plausible Boolean fragment slogan can fail without the right anchor conditions.

### C10. Specify normalized induced chain maps

A monotone map may identify vertices of a simplex. In the normalized simplicial chain complex the image of that simplex is zero when degenerate. This is standard and does not invalidate v0.1 functoriality, but should be written in the implementation contract. An unqualified formula that always sends a k-chain to a k-chain of distinct vertices would be wrong.

### C11. Preserve metric monotonicity hypotheses

Retain old weights and only add nonnegative new weights when asserting d_new>=d_old. Renormalization can violate this: a pair at old distance 1 can have distance 1/2 after adding a constant observation and averaging over both coordinates. Its edge then enters, rather than leaves, a fixed-scale Rips complex. Indexed weights and duplicate observations are presentation data, not topology invariants.

### C12. Clarify the information lost by relative groups

U and G are well-defined relative homology of model-signature restrictions, not complete invariants of premise semantics or entailment. If the only observation family is empty on two distinct valuations, a proper nonempty premise restriction may leave the same singleton signature poset. All relative groups vanish although the premise removed a valuation. Likewise, zero inference-gap homology does not imply semantic entailment.

The actual signature-difference cochain is exact by definition. Nonzero H1 integration obstructions arise for independently prescribed local edge data, as in v0.1 Example E, not from the genuine signature differences themselves.

### C13. Correct scope of combinatorial computations

Rename the last height-two repair-forest CSV column to make explicit that it counts **nonredundant neutral** cases. Redundant profiles also give the empty rooted forest. Report fixed-natural-linear-extension enumeration, not all labelled posets or one representative per isomorphism class. Preserve successful run limits; the attempted six-state two-bit extension did not finish and contributes no exhaustive result.

Rename Betti-only variables/reports labelled “homotopy” to “homology” unless a separate collapse/beat/fundamental-group argument is actually used. Keep -O disabled, since the supplied and independent scripts use assertions.

## Suggested compact replacement theorem statement

Let P be a finite poset with no chain of four elements, let b:P->{0,1}, and define x<=_Q y iff x<=_P y and b(x)<=b(y). Write K=Delta(P), L=Delta(Q). Then the integral relative boundary from deleted triangles to deleted edges is a reduced oriented graph-incidence matrix. Consequently, the following are equivalent: L->K is a homotopy equivalence; it is a simple-homotopy equivalence; K collapses to L; it induces homology isomorphisms over any one field; it induces integral homology isomorphisms; and every component of the associated incidence graph is a tree with exactly one designated root. The complete relative integral homology is free, with ranks equal to the rootless-component count in degree one and cycle rank in degree two.

This is the strongest clean theorem to carry into the focused manuscript. Its general mathematics is graph incidence plus relative collapse; its contribution claim must concern the exact binary order-thinning characterization.
