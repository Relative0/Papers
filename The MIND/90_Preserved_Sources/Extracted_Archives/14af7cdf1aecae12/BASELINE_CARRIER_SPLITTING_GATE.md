# Carrier-Splitting Research Gate

**Project:** Mathematical Reconstruction of Matte-Blanco's Unfolding Function and Mental Space  
**Date:** 29 September 2026  
**Status:** **Gate passed in a substantial restricted sense.** The carrier-splitting problem admits an exact reduction in all finite cases and a complete integral classification in weighted height at most two. A universal all-height rooted-forest classification is impossible.

## 1. Main structural result

Let `Q` be the current finite T0 quotient of realized observation signatures and add one Boolean observation `psi`. The refined quotient is

`Q^psi subseteq Q x {0,1}`

with product order, and `pi: Q^psi -> Q` forgets the new bit.

For each coarse state `s`, its refined fiber is one of `{0}`, `{1}`, or `{0,1}`. Define the **split completion** `Qhat^psi` on the same refined carrier by declaring all copies over a strictly smaller coarse state to lie below all copies over a larger coarse state, while keeping `0<1` inside a split fiber.

Then:

1. `Qhat^psi -> Q` is homotopy-neutral and in fact beat-reduces to a copy of `Q`.
2. `Q^psi` is exactly the one-bit monotonicity thinning of `Qhat^psi`: a split-completion comparison is retained iff its bit labels are nondecreasing.
3. The mapping cone of the actual carrier-splitting map has the same homology as the relative pair

   `H_*(Delta Qhat^psi, Delta Q^psi)`.

This is the crucial reduction. Carrier splitting is not an unrelated fourth mechanism: it is a **homotopy-neutral state blow-up followed by a same-carrier order defect**.

## 2. Exact all-height chain model

The relative chain complex is free on chains of `Qhat^psi` whose bit word contains a descent `1...0`.

Thus a relative k-cell is exactly a strict chain

`x_0 < ... < x_k`

whose bit word is not weakly increasing. Its boundary is the usual alternating simplicial boundary, with every face whose bit word becomes monotone set to zero in the relative quotient.

This gives a finite, explicit, coefficient-independent input model at every height. It depends only on:

- the old signature poset `Q`; and
- the three-valued fiber profile `{0}`, `{1}`, `{0,1}` at each coarse state.

The number of worlds inside an old observational class is irrelevant after that profile has been formed.

## 3. Homotopy-neutrality criteria

Write

- `A_1 = {s : a refined state (s,1) exists}`;
- `A_0 = {s : a refined state (s,0) exists}`.

If `A_1` is an upset in `Q`, choose the greatest available bit in each fiber. This gives a monotone section `r_+ : Q -> Q^psi` with `id <= r_+ pi`, proving `pi` is a homotopy equivalence.

Dually, if `A_0` is a downset, choosing the least available bit gives a monotone section and again `pi` is a homotopy equivalence.

Important corollaries:

- if every old class has at least one `psi=1` world, the split is homotopy-neutral;
- if every old class has at least one `psi=0` world, it is homotopy-neutral;
- if **every old class genuinely splits**, then `Q^psi = Q x {0<1}` and the projection is homotopy-neutral.

So duplication itself does not create the defect. The defect is generated by **incompatible outcome availability along old comparisons**.

## 4. Fiber localization

For a coarse state `s`, the lower fiber `pi^{-1}(Q_{<=s})` has maximum `(s,1)` whenever `s in A_1`. Therefore all possible lower-fiber obstructions localize to the 0-only coarse states `A_0 \ A_1`.

Dually, upper-fiber obstructions localize to the 1-only states `A_1 \ A_0`.

This places the exact chain model next to the classical Quillen/Bjorner-Wachs-Welker poset-fiber theory without reducing the result to a nerve argument.

## 5. Complete integral classification in weighted height <= 2

Let `C=A_0 cap A_1` be the set of genuinely split coarse states and define

`h_psi(Q) = max_chain (coarse chain dimension + number of split states on that chain)`.

This is exactly `dim Delta(Qhat^psi)`.

When `h_psi(Q) <= 2`, the relative complex has only deleted edges and triangles. A deleted edge is an inversion

`(s,1) < (t,0)` with `s<t`.

A deleted triangle has one of the four nonmonotone bit patterns

`010, 100, 101, 110`.

As in the companion one-bit thinning theorem, these data form a rooted incidence graph `G_psi(Q)`. Then

- `H_2(Cone Delta pi; Z) ~= Z^{beta_1(G_psi)}`;
- `H_1(Cone Delta pi; Z) ~= Z^{c_0(G_psi)}`;
- all other reduced integral cone homology vanishes;
- the boundary matrix is totally unimodular;
- the same Betti ranks therefore hold over every field;
- cone acyclicity is equivalent to `G_psi(Q)` being a rooted forest;
- equivalently the split-completion order complex collapses onto the actual refined order complex;
- equivalently `Delta pi` is a homotopy equivalence.

This is the nontrivial exact classification sought at this gate.

## 6. Sharpness: why there is no universal forest theorem

The unrestricted carrier-splitting problem contains same-carrier one-bit thinning as the special case with no genuinely split coarse state. The companion structural-computation work already proves that one-bit thinning in height three can have relative integral torsion and, in unrestricted height, can encode arbitrary finite-poset homotopy types inside a contractible coarse cone.

Therefore the weighted-height-two theorem marks a genuine mathematical boundary. Above it, no coefficient-independent rooted-forest criterion can classify the whole problem.

If one insists on examples with an actual split, a neutral split component can be adjoined without altering positive-degree cone homology, so the higher-dimensional obstruction is not an artifact of the no-split limit.

## 7. Exhaustive finite verification

`verify_carrier_splitting.py` exhaustively checked all naturally labelled finite posets on at most four coarse states (deduplicated after transitive closure) and every three-valued fiber profile `{0}`, `{1}`, `{0,1}`.

Results:

- 3,450 poset/profile cases tested;
- 2,744 contained at least one genuine split;
- 545 had nonzero cone homology;
- 305 of those nontrivial cases contained a genuine split;
- 2,172 lay in weighted height <= 2 and all matched the rooted-incidence formula;
- all 2,656 cases satisfying one of the monotone-section criteria were cone-acyclic;
- the direct normalized-chain mapping cone and the relative split-completion complex agreed in every case.

The computation is evidence for the formal proofs, not a substitute for them.

## 8. Literature/priority position

The following ingredients are standard and should be credited explicitly:

- beat-point reductions and strong deformation retracts of finite T0 spaces (Stong);
- Quillen-type fiber criteria and their simple-homotopy refinement (Barmak);
- homotopy decompositions from poset fibers (Bjorner-Wachs-Welker);
- non-Hausdorff mapping cylinders and relation cylinders in finite-poset topology (Fernandez-Minían).

The candidate project-specific contribution is narrower: **the exact observation-theoretic factorization of a T0 carrier split into a neutral lexicographic expansion plus one-bit thinning, and the transfer of the existing exact one-bit defect theorem to that changing-carrier process.** I did not find this exact formulation in the searched literature.

## 9. Recommendation

The research gate has succeeded. The carrier-splitting section is now mathematically strong enough to remain in the draft, and it is substantially more specific than generic cover-refinement or nerve theory.

The next theorem should not try to force a universal all-height forest rule. A better target is a higher-dimensional inversion-complex theorem under additional structure, for example:

- coarse intervals that are shellable or Cohen-Macaulay;
- bounded comparability/treewidth conditions;
- explicit lower-fiber connectivity conditions that make the Bjorner-Wachs-Welker decomposition computable;
- special classes of observation posets such as distributive subposets of Boolean cubes, Horn/dual-Horn signature sets, or the height-two/three regimes already arising in ProLT.

A second useful direction is to characterize exactly when the monotone-section criterion is not merely sufficient but necessary inside such restricted classes.
