# Hostile referee reports

These are internal independent agent audits and an integration review, not external peer review.

## Referee 1: structure and topology

The one-bit source theorem is valid with the stated height convention and order-complex target. Formal roots include isolated coarse components; matrices retain every descent row. The full equivalence follows from relative acyclicity, graph incidence and free edge-triangle collapse.

The restriction theorem is stronger than the tempting induced-subgraph description: triangle provenance and root splitting must be retained. The decisive zero-row property proves kernel monotonicity. A safe query can lose surjectivity through unrooted residual components; it cannot acquire a new column cycle.

Objection resolved: the first matroid slogan "basis of the repair matroid" misses unspanned rows. Actual column matroids undergo deletion; the full-rank [B,I] augmentation supplies the correct basis criterion and an exact minor operation.

The two depth families and the exact parity recurrence were reconstructed independently. The recurrence's lower bound requires both restricted-library equivalence and the safe singleton-prefix inequality. These details are now explicit.

Remaining concern: the strongest depth penalties already occur in height one. The genuinely height-two phenomenon is deactivation and possible loss of feasibility after a legal first query. Publication positioning must reflect this.

## Referee 2: algorithms and priority

The support DP is ordinary minimax decision-tree search with a state-dependent legal-test map; primary prior sources already contain that architecture. It is not a new general adaptive framework.

RF-DEPTH hardness transfers on antichains, where topology imposes no restriction. This does not prove RF-IDENT hard. Polynomial feasibility under hereditary legality is valid, and yields a complete height-one algorithm. A separate proof is still required for the general height-two classification.

The sharp oriented-library example is sensitive to query polarity; complementing its code bits removes that example's penalty. This does not defeat the separately proved complement-closed parity theorem. The latter gives an exact linear penalty and a stronger structured-family result.

The literature search was targeted and used primary sources. No assertion of exhaustive coverage or first priority is justified. Generic rooted forests, graphic matroids and decision trees are established.

## Referee 3: computational and integration checks

All naturally labelled height-at-most-two posets through n=6 and all Boolean queries were compared by separate graph and matrix implementations. The exact-height-two subset reproduces the source counts. All effective oriented libraries through n=4 were enumerated, with clearly marked seeded sampling beyond that range.

A separate original-query tree solver checked 1,730 small cases. Reported protocols map every local query to an actual supplied original query. A third implementation verified the exact boundary restriction assertions in 337,138 cases.

No count is described as an isomorphism-class census. No random sample is described as exhaustive. Constants and query complements are handled explicitly. Computational patterns are not promoted to theorem status without proofs; the parity formula received two independent proof audits after its discovery.

Known v0.5 errors were independently rediscovered but are credited as existing claim-table corrections. A1's maximum-one statement is preserved while correcting the overstrong sentence about every path.

## Gate verdict

The mathematical package survives this internal audit. The substantive results are exact repair dynamics, minimal nonhereditary behavior, sharp finite gaps and an exact complement-closed family. Publication priority and general height-two RF-IDENT complexity remain open. The next step should add or settle one of those substantive items, rather than extend terminology.
