# Reproducibility material

Code, data, receipts and original logs are retained with their intact research/review bundles under this paper's `Supporting_Research`, `Reviews`, `Manuscript_Versions` and `Archive_Only_Content`. Packaging helpers, where supplied, are in `Packaging`. Use [this paper README](<../README.md>) to select the correct version.

This organization verified file bytes, archive CRCs and recorded hashes; it did not rerun scientific experiments or rebuild manuscripts. Historical scripts can contain original absolute paths. Work in a disposable copy and resolve paths deliberately before rerunning; do not execute a packaging script in the preserved source area. [Source manifest](<../../../00_Index_and_Manifests/source_manifest.csv>) records all original and new locations.
