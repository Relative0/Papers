# Khrennikov / Matte-Blanco Priority Map

## Scope

This map separates (a) Matte-Blanco's psychoanalytic source ideas, (b) pre-2015 ultrametric/p-adic cognitive modeling, (c) the 2015 thesis, and (d) the corrected quotient/observation synthesis proposed in this audit.

## Chronology

### 1975 — Matte-Blanco

Matte-Blanco's two characteristic themes are generalization into broader classes and reversal/symmetrization of relations. The psychological claim is not itself an ultrametric theorem.

### 1998-2010 — Khrennikov program

Khrennikov develops a sustained program in which p-adic/m-adic geometry represents hierarchic mental space. The 1998 paper explicitly says that two ideas are p-adically close when they have a sufficiently long common root. By 2007, branches, balls, associations, ideas, and conscious/unconscious flows are already part of the program. By 2010, categories encoded by ultrametric balls are explicit.

### 2007/2008-2014 — Matte-Blanco meets ultrametricity

Lauro-Grotto and especially Murtagh connect Matte-Blanco directly to ultrametric/hierarchical modeling before the 2015 thesis. Consequently, a publication today should not present “Matte-Blanco + ultrametric topology” as new.

### 2015 thesis

The thesis independently develops a useful prefix-ball concept hierarchy, but it conflates equal-radius ball coincidence with indiscrete topology and topological indistinguishability. It also sometimes treats attribute-forgetting as if it were set intersection.

### 2016-2026

Subsequent papers continue p-adic/ultrametric consciousness/unconsciousness themes and broader p-adic biology/cognition. The basic terrain is therefore established.

## Defensible novelty target

A plausible modern contribution is not “the unconscious is p-adic.” It is closer to:

> **A resolution-limited hierarchical cognition model in which an ultrametric state space is separated from an explicit observational quotient/filtration, with Matte-Blanco symmetry represented as invariance within quotient fibers.**

This formulation has three advantages:

1. it repairs the topology;
2. it distinguishes ontic state differences from accessible distinctions;
3. it connects rooted trees, quotients, sigma-algebra filtrations, information gain, and group invariance in one structure.

## Priority caution

The present web audit found no source making exactly this combined repair the main theorem-level architecture, but this is **not sufficient to claim novelty**. A serious priority claim should still search MathSciNet/zbMATH, Scopus/Web of Science, PsycINFO, symbolic dynamics, hierarchical Bayesian cognition, state aggregation/coarse-graining, and observational equivalence literature.
