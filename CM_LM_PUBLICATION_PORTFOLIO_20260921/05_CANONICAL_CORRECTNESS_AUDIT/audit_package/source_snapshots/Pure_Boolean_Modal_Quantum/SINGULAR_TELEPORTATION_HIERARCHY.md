# Singular-resource teleportation hierarchy in the pure-Boolean CM ring

## First: the `(0,2)` versus `(0,0)` point

Yes: the state

`|00> XOR delta|11>`

is **Smith class `(0,2)`**, not `(0,0)`.

The reason is that

`delta = E0 XOR E2 = u^2`,

so its coefficient matrix is

`D_(0,2) = diag(E0, delta) = diag(u^0,u^2)`.

Its Smith valuations are therefore `(0,2)`. Its determinant is `delta`, which is nonzero but is a **nonunit zero divisor** (`delta^2=0`). Hence it is singular over the CM ring.

By contrast, the support Bell state

`|00> XOR |11>`

has coefficient matrix `diag(E0,E0)=diag(u^0,u^0)`, so it is Smith `(0,0)`. Its determinant is the unit `E0`, so it is invertible.

Therefore:

- `(0,0)` **succeeds** at deterministic universal exact teleportation;
- `(0,2)` **fails** deterministic universal exact teleportation;
- the earlier `B_star` resource `|00> XOR delta|11>` is precisely an example of that `(0,2)` failure.

The failure is only for **universal exact transfer of an arbitrary state in `A^2`**. The rest of this document asks what useful tasks remain below that threshold.

---

## Setup

Let

`A = F2[u]/(u^4)`

and let a two-party resource be represented, up to invertible local changes of basis, by the Smith representative

`D_(a,b) = diag(u^a,u^b)`,

with

`0 <= a <= b <= 4`, `u^4=0`.

For an analyzer outcome whose row is reshaped into `R_m`, Bob's branch map is

`T_m = D_(a,b)^T R_m^T = D_(a,b) R_m^T`.

All claims below remain inside the project's pure-Boolean `A`-linear/modal calculus. No Born probabilities are introduced.

# H1. Exact restricted-state teleportation

## Result

**[THEOREM / PROVED]** The largest common set of states that can be recovered exactly by the same outcome-conditioned `A`-linear corrections is controlled by the first Smith exponent `a`:

| Smith shape | Maximum exact common state family |
| --- | ---: |
| `(0,0)` | all `256` states of `A^2` |
| `(0,b)`, `b>0` | `16` states: one free `A`-line |
| `a>0` | only the zero state |

For `(0,b)`, a canonical maximal family is

`L = { x|0> : x in A }`.

Thus `(0,2)` cannot teleport an arbitrary `A|0> XOR B|1>`, but it **can** teleport every state `A|0>` exactly, on all four outcomes, with a suitable reversible analyzer.

### Explicit four-outcome analyzer

Use reshaped analyzer rows

```text
R0 = [[1,0],[0,0]]
R1 = [[1,1],[0,0]]
R2 = [[1,0],[1,0]]
R3 = [[1,0],[0,1]]
```

where `1=E0`. Their four vectorizations form an invertible `4x4` analyzer over `A`.

For every canonical resource `D_(0,b)` and every input `(x,0)`, every branch retains `x` in Bob's first coordinate. The fixed correction

`P = [[1,0],[0,0]]`

therefore recovers `(x,0)` exactly on all four outcomes. All 16 values of `x` were checked for every `b=0,1,2,3,4`.

## Why 16 is maximal for `(0,b)`, `b>0`

For any branch and correction, the recovered map has the form

`K = C T`.

Reducing modulo the maximal ideal `(u)` gives a map over `F2`. A `(0,b)`, `b>0`, resource has residue-field rank one, so `rank(K mod u) <= 1`.

The exact fixed states form the submodule

`Fix(K)=ker(I-K)`.

Its socle can therefore have dimension at most one over `F2`. By the finite-chain-ring module decomposition, such a submodule has length at most four, hence cardinality at most `2^4=16`.

The explicit free-line protocol attains the bound.

## Why `a>0` cannot recover even one nonzero unknown state exactly

If `a>0`, every entry of every branch map lies in `(u)`. Hence every entry of `K=CT` also lies in `(u)`, so `K mod u=0`.

If a nonzero vector `psi` were fixed by `K`, then the cyclic `A`-submodule generated by `psi` would contain a nonzero socle vector `s` with `u s=0`. `A`-linearity would give `K s=s`, but because every entry of `K` is divisible by `u`, `K s=0`, a contradiction.

So the only fixed vector is zero.

### Important interpretation boundary

The 16 states on a free line are 16 **exact ring vectors**. Under support-only modal semantics, some unit-scaled vectors are operationally indistinguishable. Therefore the number 16 is an algebraic state count, not a claim of 4 classical bits of physical communication capacity.

# H2. Quotient-state transfer

A singular resource may destroy part of the input while preserving a well-defined quotient.

For

`D_(a,b)=diag(u^a,u^b)`,

multiplication by `u^a` has kernel `(u^(4-a))`, and multiplication by `u^b` has kernel `(u^(4-b))`. Therefore the canonical retained quotient is

`Q_(a,b) = A/(u^(4-a)) + A/(u^(4-b))`.

Its cardinality is

`|Q_(a,b)| = 2^(8-a-b)`.

This is an algebraic distinguishability count only, not a Born-information or channel-capacity claim.

For example:

- `(0,0)`: `A + A`, 256 classes;
- `(0,2)`: `A + A/(u^2)`, 64 classes;
- `(1,1)`: `A/(u^3) + A/(u^3)`, also 64 classes;
- `(2,2)`: `A/(u^2) + A/(u^2)`, 16 classes;
- `(3,3)`: `A/(u) + A/(u)`, 4 classes.

The equality of the raw class counts for `(0,2)` and `(1,1)` hides a real structural difference: `(0,2)` retains one full free `A` coordinate, whereas `(1,1)` retains two equally truncated coordinates.

## A fixed canonical quotient target

To make quotient transfer operationally definite, take the target to be

`D_(a,b) psi`.

For an analyzer row `R_m`, a branch is called quotient-correctable when some `A`-linear `C_m` satisfies

`C_m D_(a,b) R_m^T = D_(a,b)`.

Then Bob recovers the **same fixed quotient encoding** `D_(a,b) psi`, independent of the outcome label.

## Complete four-outcome classification

**[THEOREM / PROVED + FINITE VERIFICATION]** In a reversible four-outcome analyzer, the maximum number of outcome rows that can be quotient-correctable is:

| Smith shape | Max quotient-correctable outcomes out of 4 |
| --- | ---: |
| `a=b<4` | **4** |
| `a<b<4` | **2** |
| `a<4, b=4` | **3** |
| `(4,4)` | 4, but quotient is trivial |

### Equal-valuation singular classes are special

For

`D_(a,a)=u^a I`,

and any invertible reshaped analyzer row `R`,

`D R^T = u^a R^T`.

Bob can apply `(R^T)^-1`, giving

`(R^T)^-1 D R^T = D`.

The existing Bell analyzer has four invertible reshaped rows. Therefore `(1,1)`, `(2,2)`, and `(3,3)` all support **deterministic four-outcome transfer of their fixed quotient**, even though none can exactly recover any nonzero full ring state.

This is a sharp operational distinction from the off-diagonal classes.

### Off-diagonal nonzero classes

For `a<b<4`, after removing the common `u^a` factor and examining the induced filtration, a quotient-correctable analyzer row must reduce modulo `(u)` to an invertible upper-triangular matrix. Over `F2` there are only two such reductions:

```text
[[1,0],[0,1]]
[[1,1],[0,1]]
```

Their span has dimension two inside the four-dimensional analyzer-row space. Since the four rows of a reversible analyzer must reduce to a basis of that four-dimensional space, **at most two** can be quotient-correctable. Two are achievable, so the bound is exact.

Thus `(0,2)` can preserve its fixed quotient

`(A,B) -> (A, delta B)`

on at most two analyzer outcome labels in one reversible four-outcome protocol.

### Rank-one separable classes

For `b=4`, the canonical target has only one surviving coordinate. The allowed successful row reductions span a three-dimensional subspace, so at most three analyzer outcomes can be fixed-quotient successes. Three are achievable.

This is another reminder that restricted or quotient transfer by itself is **not** a nonseparability witness.

# H3. Postselection / "probabilistic" teleportation

The CM modal calculus used here has possible/impossible outcomes but **no probability measure**. Therefore the correct intrinsic language is **heralded/postselected success**, not numerical success probability.

## Full unknown state

**[THEOREM / PROVED]** Postselection does not rescue universal exact full-state teleportation for any singular resource.

From the general branch identity

`T_m=M^T R_m^T`,

we have

`det(T_m)=det(M) det(R_m)`.

If `M` is singular, `det(M)` is a nonunit. A product containing a nonunit cannot be a unit in this local ring. Hence `T_m` is never invertible, for **any** analyzer row, including an analyzer row designated as a postselected success event.

Therefore every singular Smith class has

`0`

universally exact postselected full-state outcomes.

This differs from ordinary complex quantum theory, where a partially entangled pure state can still have nonzero Schmidt coefficients and conclusive faithful teleportation can be possible with less-than-unit success probability. Here the obstruction is ring-theoretic: the relevant CM coefficient is a **nonunit/zero divisor**, not merely a smaller nonzero field amplitude.

## Quotient state

Postselection does help for the fixed quotient task:

- equal classes: 4 success labels, so no postselection needed;
- off-diagonal `a<b<4`: at most 2 success labels;
- rank-one `b=4`: at most 3 success labels.

These are counts of allowed outcome labels only. They must not be converted into `1`, `1/2`, or `3/4` probabilities without adding a probability rule not present in this model.

# H4. Local ancillas do not activate singular resources

**[THEOREM / PROVED]** Product local ancillas cannot turn a singular two-party resource into a universally exact teleportation resource under `A`-linear operations.

Let Alice add arbitrary local ancillas in fixed states and perform an arbitrary larger linear analyzer. After contracting Alice's ancillas and her half of the resource, any branch from the unknown `A^2` input to Bob still factors through the resource matrix:

`T = V M^T R^T`,

where `R` is the effective Alice contraction and `V` includes Bob's local ancilla embedding/processing.

Reduce modulo the maximal ideal `(u)`. A singular `2x2` matrix over the local ring has

`rank_F2(M mod u) <= 1`.

Therefore

`rank_F2(T mod u) <= 1`.

If Bob had an `A`-linear decoder `C` with `C T=I_2`, reducing modulo `(u)` would give

`Cbar Tbar = I_2`,

whose right-hand side has rank two. Contradiction.

So uncorrelated local ancillas do not help.

# H5. No finite-copy activation of a singular resource

The same residue-rank argument is stronger than the single-copy statement.

For `k` shared copies, the resource coefficient matrix is

`M^(tensor k)`.

Over the residue field,

`rank(Mbar^(tensor k)) = rank(Mbar)^k`.

For a singular CM resource, `rank(Mbar)` is either zero or one, hence every finite tensor power still has residue rank at most one.

Any Alice contraction from the two-dimensional unknown input into her side of this larger resource, followed by any Bob decoder, therefore has residue rank at most one. It cannot have a left inverse onto `A^2`.

**[THEOREM / PROVED]** No finite number of copies of a singular two-party CM resource can activate deterministic or postselected universal exact one-bit teleportation within the `A`-linear architecture.

This includes `(0,2)`: two copies, three copies, or any finite number of copies do not cross the universal exact threshold.

The statement also survives arbitrary product local ancillas and local pre/post-processing. An additional **nonlocal** `(0,0)` resource would of course change the resource being studied and trivially evade the hypothesis.

# What this says specifically about `(0,2)`

The earlier `B_star` resource is not simply a dead end. Its exact position in the hierarchy is now:

1. **Universal exact arbitrary-state teleportation:** no.
2. **Any postselected universally exact branch:** no.
3. **Exact restricted transfer:** yes, a full free line `A|0>` of 16 ring vectors, deterministically across four outcomes with an appropriate analyzer.
4. **Canonical quotient retained:** `A + A/(u^2)`, 64 equivalence classes; equivalently the first coefficient is retained fully and the second only modulo the part annihilated by `delta=u^2`.
5. **Fixed quotient transfer:** at most two of four analyzer outcome labels can be made correctable to the same canonical quotient target.
6. **Local-ancilla activation:** no.
7. **Any finite-copy activation to universal exact teleportation:** no.

This is substantially finer than the original binary success/failure theorem.

# Literature boundary

Ordinary quantum information has a substantial literature on conclusive/probabilistic teleportation with nonmaximally entangled resources. Examples include Son et al., *Phys. Rev. A* **64**, 064304 (2001), DOI `10.1103/PhysRevA.64.064304`, and Roa, Delgado & Fuentes-Guridi, *Phys. Rev. A* **68**, 022310 (2003), DOI `10.1103/PhysRevA.68.022310`.

Those results should not be imported mechanically into the CM ring. Over the complex field, a nonmaximal Schmidt coefficient can still be invertible as a scalar; over the CM chain ring, `u`, `delta=u^2`, and `Omega=u^3` are nonunits, and zero-divisor/valuation information loss survives every `A`-linear correction. The residue-rank no-activation theorem above is specifically a chain-ring effect.

Finite-field/modal theories also already have teleportation analogues; see James, Ortiz & Sabry, arXiv:1101.3764. The present contribution is the finer Smith/valuation hierarchy for the CM ring, not the general idea of modal teleportation.
