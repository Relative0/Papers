## Audit scope clarification (2026-09-17)

The universal teleportation result uses **general invertible Boolean-linear dynamics**. The fixed Bell analyzer is not Boolean-orthogonal, and two of its four exact correction maps are non-orthogonal. An exhaustive scan of all 65,536 possible single-outcome P-block analyzer row-blocks found no row-block that could simultaneously belong to a Boolean-orthogonal analyzer and yield an orthogonally correctable branch for the support-Bell resource. Thus orthogonal-only universal teleportation is not established; for the support-Bell resource in this P-block analyzer class, the stricter orthogonal-only version has a negative result.

All contextuality claims remain conditional on the explicit modal possible/impossible measurement contract and the admitted 192 reversible projective bases. Multi-party states use a shared 4-bit phase register rather than independent local 4-bit phase registers.
