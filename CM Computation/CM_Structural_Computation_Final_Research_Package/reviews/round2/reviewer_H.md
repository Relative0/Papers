# Round 2 reviewer H: Fresh role: information-theory and query-complexity specialist

**Disclosure:** same-assistant adversarial specialist-role assessment of frozen Draft 2; no independent external review.

The paper promises persistent query semantics, yet its most compact rank-count description is a pair of histograms. A histogram forgets where its values came from. Two row permutations can preserve the unconditional count and both profile histograms while changing the count under a named-variable restriction.

Require an explicit two-variable counterexample and a proposition: any representation that answers every fully assigned exact-count query must distinguish every function it supports. This does not forbid compression on structured subclasses; it rules out a lossy summary being silently promoted to an all-query representation.

A second useful boundary is exact source verification. In a black-box bit-query model, distinguishing the zero truth table from an unknown single spike needs every assignment on the all-zero transcript. This remains true if both sources have fixed-cut GF(2) rank at most one. But formula syntax, proof certificates, trusted authenticated summaries, bounded error, and word-wide reads are different access models. State those exclusions.

These are elementary limits, not a claim to new decision-tree complexity. Their value is to prevent an overclaim in the computational contract. Strongest argument for the report: it can make these boundaries unusually concrete. Strongest against a theory-paper claim: the results are elementary and lack a priority separation.
