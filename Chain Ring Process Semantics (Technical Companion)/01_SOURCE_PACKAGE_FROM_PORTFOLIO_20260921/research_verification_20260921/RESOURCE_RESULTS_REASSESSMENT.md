The three code columns count different experiments. A d-dimensional A carrier expands to a 4d-dimensional binary carrier, so the unrestricted binary single-carrier baseline is 4d. Calling every increase over d a binary communication advantage would be incorrect.

## Conversion information that survives

One-copy A-linear selected filters have exact Smith component order. Reversible A-linear or normalizer operations between encoded endpoints preserve the full Smith list. Unrestricted binary reversible operations retain only R. Complete filter monotones are threshold counts c_j=#{i:a_i<j}; h and contextuality class can increase under selection. Filtered regular ranks are useful but their inequalities alone do not give the filter order.

For independent k copies retaining all phase registers, free-target extraction is governed by r0^k, an elementary residue-rank/unit-minor criterion. Resolved disposal changes that task: the known two-copy construction reaches a single-register E_A(I_2) even from unit sectors alone. Blind disposal in that construction is mixed. A general unobserved-disposal classification remains unproved, and should not be presented as an established impossibility.

## Equality and resource-accounting cautions that are actually needed

Unit multiples preserve original coarse supports but can be distinguished with binary coefficient effects. An invertible conversion between states is not equality of their outcomes for a fixed full-binary measurement. Encoding a balanced product C can create a binary entangled state E(C); the phase correlation in E(C) is part of the supplied resource. Raw-vector transfer must return the original vector, not merely a unit multiple or a quotient representative. Classical outcome labels do not grant classical access to all amplitudes.
