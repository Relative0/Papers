# Frozen scope of this note

This is a verification-note source accompanying an existing technical companion, not a fourth-paper submission recommendation.

Allowed claims: scalar obstruction; primitive and embedding counterexamples; explicit closed binary instrument contract; faithful lax restriction of scalars; exact coarse-support encoding with nonmonoidal limits; selected Smith filter order; exact algebra/coarse-measurement stabilizer inherited from the prior local review; decoder-dependent code counts; fixed-phase unit-rank criterion; inherited resolved-disposal example and its mixed unobserved output.

All have explicit proofs in main.tex or named complete proofs in the accompanying theorem ledger and prior local review. There is no deferred lemma needed by the frozen claims. The proof status is written analytic proof plus stated finite checks, not machine-checked proof or independent human review.

Not claimed: mathematical firstness, a new tensor-closed all-nonzero shared-A theory, general multipartite classification, full assisted/disposal conversion classification, physical probabilities, implementation, speedup, or unrestricted communication advantage.
