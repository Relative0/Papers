## Version convention

**Site reading copy 1** is the first byte-for-byte PDF selected for this website. It is a website release label, not a claim that the manuscript itself is internally “v1.0,” journal accepted, or externally peer reviewed. The source revision printed in each PDF remains visible on the paper page. If a PDF changes later, give it a new site-release number and filename; preserve the earlier file for citations or explicitly retire it with a notice. This follows the general archival principle that a cited version should identify fixed file contents.

## Byline check

A byline is simply the author name on a paper's title page. This check compares that printed name with the website's credit and with the other selected copies. The site identifies Brian Theory as Brian Droncheff and reports each PDF's printed byline without rewriting any PDF. This resolves the website's explanation of the two names while preserving the original manuscript files. It does not decide journal authorship, affiliations, acknowledgments, or any future coauthor claims.
