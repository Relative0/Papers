## Is “ZIP everything except the latest results” clean?

**No, as a blanket move.** “Latest” is not a reliable boundary: a current manuscript can depend on older `.tex`, bibliography, code, data and reviews; a negative or superseded result can be essential to the publication claim. There are already original delivery ZIPs and archive-only material, so repacking them adds little benefit and risks obscuring version provenance. PDFs and ZIPs usually offer little further compression. The collection has 166 *inherited* missing historical links already; moving loose directories would create additional path breaks unless each dependency and index were revised.

Particular paths to leave loose now include each paper's `COLLECTION_README.md`, current manuscript source/PDF and bibliography, latest review and reproducibility entry points; `README.md` and `00_Collection_Index`; The MIND; both Paper U review workspaces; `Structured Factorization` (including Phase 5B and the September 30 campaign); the current CM Computation and structural-computation handoffs; the root process-semantics ZIP used by P01's validation script; and the newly created website publication checkouts. The latter are post-baseline working directories, not redundant paper archives. Do not infer scientific duplication merely from folder names: the [paper crosswalk](<PAPER_CROSSWALK.md>) assigns separate owners to CM computation, structural computation and Factorization.

A **selective, per-paper cold archive** is viable later. Start with an explicitly named older extracted package only when its *complete* bytes are already in a retained original ZIP or a newly made ZIP has been verified member by member. Keep distinct drafts and original ZIPs. For each candidate, first check references from current scripts, TeX, manifests, review records and links; record the old path and intended `archive.zip!/member` locator; create the archive in staging with safe relative paths; verify archive SHA-256, CRC, every member SHA-256 and a test extraction; then update navigation and recheck the current manuscript workflow. Include the recovered Factorization baseline in any future preservation accounting.

**Decision:** keep the present loose reading heads and original ZIPs. Do not perform a bulk ZIP-and-remove operation. If storage or clutter later warrants action, pilot one closed historical package with the safeguards above and seek explicit authorization before removing any loose original. This recheck created its report, JSON receipt and the hash-verified historical report copy; no live source file was moved, deleted, rezipped or edited.
