# Paper and report folder names — 1 October 2026

I classified a folder by its current manuscript or report title and abstract, the version sequence, package README, review disposition and [paper crosswalk](PAPER_CROSSWALK.md). A shared evidence register, delivery package or active experiment workspace is not a new paper merely because it contains a paper copy. The type in parentheses describes the **form of the work**, not its publication readiness. The short name before the type has at most five words. The [machine-readable plan](PAPER_FOLDER_RENAME_PLAN_2026-10-01.json) records every old and new path; the [source manifest](PAPER_FOLDER_PRENAME_SOURCE_2026-10-01.jsonl), [copy verification](PAPER_FOLDER_COPY_VERIFICATION_2026-10-01.json) and [workflow audit](PAPER_FOLDER_WORKFLOW_AUDIT_2026-10-01.md) record byte preservation and path checks.
