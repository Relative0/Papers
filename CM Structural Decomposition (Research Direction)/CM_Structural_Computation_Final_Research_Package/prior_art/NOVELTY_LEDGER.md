# Novelty ledger

| Candidate | Assessment | Treatment |
|---|---|---|
| Boolean compile-once/query-many paradigm | Established KC | Background only |
| Certified compiled Boolean representation | Established, with stronger formal approaches | No first-certified claim |
| XOR/GF(2)/prototype/Kronecker primitives | Standard mathematical/decomposition antecedents | Deliberately familiar family definitions |
| Restriction closure and elementary count formulas | Direct consequences with established context | Proved for exact contract; no priority claim |
| Rank-profile formula / Walsh evaluation | Standard character-transform mechanism | Explanatory applied statement, not new transform |
| Factor-only minimal recompression | Standard exact linear algebra | Operational repair; no new rank theorem claim |
| Complement-quotient bounds | Elementary proof supplied; exact prior occurrence not cleared | Useful bounded statement; priority unclaimed |
| Fixed-cut inner-product dictionary/field gaps | Standard algebra ingredients and explicit model | Not all-order/all-representation lower bounds |
| Histogram insufficiency and all-query information bound | Elementary counterexample/counting principle | Prevents an interface mistake, not new information theory |
| Black-box zero-source bound | Elementary adversary argument | Explicit input-model boundary, not a certified-KC limitation |
| Six recovered-source contract observations | Newly executed concrete audit here | Main reproducible empirical contribution; no ordinary-producer-failure generalization |
| New reference system / legacy adapter / codec | New artifacts produced in this pass | Claim exact implementation and testing, not algorithmic primacy |
| Binary versus JSON selection sensitivity | New bounded measurement here | Encoding-specific result, not optimal compression |
| Corrected complete reload result | New bounded negative measurement here | 38 cases, actual 128-query replay; not impossibility or industry-wide conclusion |
| Whole standalone research-paper novelty | UNRESOLVED | Final report-level verdict; strengthen evidence or contribution before submission |

A proof and a novelty claim are different deliverables. No missing prior-art proof is filled in by assuming that unfamiliar CM vocabulary makes the result new.
