# Partition tooling

Run `python verify_partition.py "path/to/Papers for Publication"` for a portable, read-only verification using Python standard library only. It checks all original preserved byte streams, each manifest entry, source entry points, final content inventory and both report copies. It reports Git status when the account can read the repository.

Other scripts are preserved implementation/provenance recipes from this cleanup. They refer to the original Windows paths and intermediate work/text extraction cache and are not a one-command replay package. In particular, do not rerun mutation scripts on the completed tree. The mutation receipt and complete preservation map are the authoritative reversible path records.

Historical manuscript verifiers retain their original bytes, including absolute paths and whitespace. The verification_runs.json ledger states which two checks were executed and the single temporary output-path adaptation for the nonlinear guard verifier.
