\begin{abstract}
This planned article studies exact all-outcomes-correct linear modal query
procedures over characteristic-two fields. In a fixed pointwise oracle model,
linear relations obstruct one-query Deutsch and Deutsch--Jozsa procedures, and
an amplitude-polynomial span argument requires at least $n$ queries for the
$n$-bit Bernstein--Vazirani problem. The standard informative XOR oracle
attains the Deutsch and Bernstein--Vazirani bounds with two and $n$ queries.
These upper bounds are not asserted for arbitrary coincident oracle gates.
We distinguish genuine nilpotent-ring phase kickback from an invertible
character readout, and retain the known UNIQUE-SAT protocol as a positive
control against overbroad impossibility claims. The intended contribution is a
precisely typed query and resource separation, subject to a remaining
primary-source priority review, not a new polynomial method or a universal
no-go for modal computation.
\end{abstract}

$O_f=\bigoplus_xG_{f(x)}$ for fixed invertible target gates $G_0,G_1$.

Preparations and nonquery linear operations are independent of the oracle.
Ancillas are allowed. Every possible final outcome must carry the correct

\section{Kickback is not a character basis}

\begin{proposition}[Nilpotent-ring kickback and singular readout]

$X(1,z)^T=z(1,z)^T$, while
$H_z=\begin{pmatrix}1&1\\1&z\end{pmatrix}\sim\diag(1,u^2)$ is singular.
The shared $n$th tensor power has binary rank $4+2n$.
\end{proposition}
